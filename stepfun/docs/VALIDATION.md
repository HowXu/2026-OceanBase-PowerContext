## 结果解读与范围

固定中文回归集的最终混合检索 Recall@5 均为 100%，nDCG@5 均为 0.926；因此 INT8/WASM 与 FP16/WebGPU 在此评测集没有观察到质量下降。INT8 权重体积由 90.46 MiB 降至 22.90 MiB，压缩 3.95 倍；FP16 为 45.30 MiB，压缩约 2 倍。具体性能以原始 JSON 与技术说明为准，保留每轮而非只取最快一次。

质量探针是数值兼容性检查，不能替代完整检索质量评测。该回归集仅 20 篇文档、10 个查询，不代表通用中文检索能力。不同显卡、驱动与浏览器可能使 INT8/WebGPU 正常，也可能使其他精度不可用；应用检查实际输出后再选择后端。

初次网络下载中发生了断流，完整冷网络下载的计时未保留下来，因此不报告虚构的“冷下载加速”。下载器现在记录下载/校验耗时与 `cached` 标志并支持续传；最终报告中的 manifest 为本机已有模型的校验记录，不能当成首次下载耗时。浏览器首次初始化与预热有实测，复用会话在普通操作记录中标为零加载。

本机 Windows 原生嵌入式 seekdb 启动停滞，未声称验证通过；默认采用已实际跑通的本地 server，提供固定 Docker 镜像和连接配置。复测期间本地数据库曾重启导致 SDK 会话失效，已补充串行操作前连接检查和幂等请求的重连恢复，并通过实际关闭连接后的检索验证。
