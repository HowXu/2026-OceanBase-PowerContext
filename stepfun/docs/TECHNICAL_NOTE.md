# 拾知：一页技术说明

2026-10-28；完整复现步骤见 ../README.md。

## 链路与模型

文本导入 → 浏览器 Worker 本地向量化 → seekdb-js 写入及索引刷新 → 浏览器查询向量 → seekdb 数据库内全文与向量 RRF 排序 → 展示来源和原文。所有推理均在浏览器完成，服务端未配置 embedding 函数。

## 模型与量化

BGE-small-zh-v1.5（BAAI，MIT），使用 Xenova 发布的 ONNX；固定版本 75c43b069aac4d136ba6bc1122f995fedcfd2781。Transformers.js 3.8.1，CLS 池化、L2 归一化、512 维，查询增加中文检索前缀。直接采用发布的 INT8 动态量化（QInt8、per_channel/reduce_range）及 FP16 文件；下载后校验 SHA256。FP32 90.46 MiB、INT8 22.90 MiB、FP16 45.30 MiB；INT8 压缩 3.95 倍、FP16 压缩 2.00 倍，统计口径为单个 ONNX 图与权重。

## 数据库与连续操作

seekdb 1.4.0 本机 server；每个知识库一个集合，cosine HNSW + ngram(2) 全文索引，保存 id / document / embedding / metadata。混合检索调用 hybridSearch，由 DBMS_HYBRID_SEARCH 在库内排序。350 字符分块、50 字符重叠；SHA256 ID + upsert 实现幂等增量写入；最后统一显式刷新。集合与精度持久化，切换时清空旧结果；串行保护数据库会话，断线可恢复，向量空间不匹配拒绝写入。

## 质量保护与优化

自动模式显式优先 WebGPU，缺少适配器、加载/推理故障或数值一致性检查不通过时使用 WASM，并显示原因。本机初测 INT8/WebGPU 向量 Recall@5 仅 20%，因此加入两条探针与 FP32/WASM 的余弦一致性检查（阈值 0.98），该配置在最终版被拒绝；FP16/WebGPU、INT8/WASM 均通过。INT8/WASM 批大小 1→8 吞吐提升 1.24 倍；模型复用与一次索引刷新减少重复开销。

## 条件、口径与边界

Windows / Chromium 156，Ryzen 9 9955HX（32 线程），浏览器内存档位 16 GB，WASM 4 线程；本机 WSL Docker seekdb 2 GB / 2 CPU。20 篇中文资料、10 个标注查询，预热后重复 3 轮；向量与混合检索分开评估，按来源 ID 去重。表格质量为混合检索；查询耗时含向量化、HTTP 与数据库响应，不含绘制。下载与本地加载分开记录；原始 JSON 保留各轮、首次加载和预热数据。样例规模小，不代表通用基准；Windows 嵌入式启动停滞，采用已验证 server 路径。
